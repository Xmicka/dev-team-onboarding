# The Dev.Team — Onboarding Opening Plenary

A cinematic, scroll-driven opening plenary for the **AIESEC in Sri Lanka Dev.Team** onboarding, presented by the MCVP IM.

Built with a hand-written WebGL fragment shader (domain-warped fbm flow, mouse-reactive, section-retinting), GSAP + ScrollTrigger, Lenis smooth scroll, and an editorial type system (Space Grotesk · Instrument Serif · Inter · JetBrains Mono).

## Run locally
Just open `index.html`, or serve it:
```bash
python3 -m http.server 8777
```
Then visit http://localhost:8777

## Navigation
Scroll, arrow keys / space, or the section rail on the right.

Single self-contained file — no build step.
